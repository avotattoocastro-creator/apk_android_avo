====================================================================================================
Comprobación con el ejemplo de TI (Ls=11 µH, Ls'=16 µH): C1 = 158.3 nF (TI: 158.3), C2 = 2.34 nF (TI: 2.3)
Q ejemplo TI = 2π·1MHz·11µH/0.191Ω = 362 (> 77)

Diseño: C1 = 247 nF, C2 = 2.2 nF (+1.0 nF C5 sin montar)
Supuesto del diseñador Ls' = 10 µH -> C1 requerido = 253.3 nF; fS con 247 nF = 101.3 kHz
Con C1 = 247 nF, fS queda en 90–105 kHz solo si Ls' está entre 9.30 y 12.66 µH
  si Ls = 8 µH y C1 = 247 nF: C2 requerido = 3.21 nF; fD con 2.2 nF = 1.205 MHz; con 3.2 nF (C5) = 1.001 MHz
  si Ls = 10 µH y C1 = 247 nF: C2 requerido = 2.56 nF; fD con 2.2 nF = 1.078 MHz; con 3.2 nF (C5) = 0.895 MHz
  si Ls = 12 µH y C1 = 247 nF: C2 requerido = 2.13 nF; fD con 2.2 nF = 0.984 MHz; con 3.2 nF (C5) = 0.817 MHz

Fórmula de C2 escrita en DOCS/AJUSTE_QI.md: C2 = 1/((2π·1MHz)²·(Ls − 1/((2π·100kHz)²·C1)))
  Ls=10 µH, Ls'=10 µH: Ls − 1/(ωS²C1) = Ls − Ls' = +0.00 µH -> división por cero / negativo  (TI: 2.56 nF)
  Ls=11 µH, Ls'=16 µH: Ls − 1/(ωS²C1) = Ls − Ls' = -5.00 µH -> división por cero / negativo  (TI: 2.34 nF)
